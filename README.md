# Tic-Tac-Toe

A simple Tic-Tac-Toe web game — play against a friend locally, or just enjoy a classic 3×3 grid match.

👉 **Live Demo:**  
https://tic-tac-toe-project-beryl.vercel.app/

## 🎯 Features

- 3×3 game board with alternating X and O turns  
- Automatic detection of win / draw conditions  
- Reset / New Game option to start over
